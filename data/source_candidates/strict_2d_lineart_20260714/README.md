# 二维连续边饰线稿候选（2026-07-14）

本批次按用户反馈重新限定为二维线稿，不再把真实器物照片作为主要训练候选。所有条带都经过人工视觉验收，并按“能否追踪单一主藤、花位、一级分支和二级分支”分层。

## 目录

- `A_core/`：8 条核心候选。主藤连续，花位或果位明确，分支关系基本可追踪，可优先粗标注。
- `B_auxiliary/`：9 条辅助候选。二维线稿成立，但存在分支过密、主藤局部遮挡、结构过简、来源图局部截断等问题，不宜直接充当核心监督样本。
- `original_sources/`：原始图页或整张图录，用于核对裁剪位置、洞窟号和上下文。
- `contact_sheet.jpg`：A、B 两级全部裁剪图的总览。
- `manifest.csv`：逐图来源、层级和验收结论。

## 核心验收标准

1. 必须是二维黑白或单色线稿；彩色实物、壁画现场照片不进入本批核心集。
2. 横向母藤应可连续追踪，不能只是团花、徽章或独立模块的串联。
3. 花或果必须与藤枝存在可解释的承载关系，不能有明显贴图感。
4. 核心图至少能辨认一级分支，并尽量包含二级回卷；密到看不出父子关系的图降入 B 级或淘汰。
5. 现代练习纸、几何填充、动物主导、纯团花链和严重水印图不收。
