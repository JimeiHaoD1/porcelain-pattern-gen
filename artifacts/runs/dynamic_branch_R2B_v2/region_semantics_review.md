# R2B 区域语义理解检查点

本检查点逐项解释冻结规范中的全部区域。R2B 的执行样例固定为 `proto_sw_1_1 / seed 4101 / flower_1`，但区域语义本身不依赖 seed，不使用任何已有或候选分支曲线，也不读取 Stage 5 选择结果。

## 总体理解

区域是由主藤、花位、禁入区和剩余空间共同决定的“有宽度的角色化软生长通道”，不是画布硬分区，也不是已有分支曲线的后验包络。生成顺序固定为：局部坐标系 → 硬约束区 → 角色入口区间 → 引导中心线 → 变宽软通道 → SW1 回环嵌合 → 裁剪/容量 → 在任何分支几何之前冻结计划。允许留白，禁止为了覆盖画布而补区域。

## 硬约束区域

### `flower_forbidden_region`

1. 服务关系：保护花心，阻止普通、平衡和收束结构穿入花体。
2. 入口：它不是生长通道，没有分支入口。
3. 经过：由目标花位的中心、`rx/ry` 与冻结保护 padding 扩张成闭合曲线。
4. 出口：无出口；边界仅作为约束。
5. 邻接：support 只能接近花位下侧目标扇区；wrap 只能沿其外围运行；它优先于所有角色区。
6. 适用原型：所有含花原型；R2B 固定实例只生成目标 `flower_1` 的一个禁入区。
7. 禁止：缩小禁入区以让曲线通过；用矩形、扇形或固定圆替代；让普通/balance 穿入内部。

### `backbone_protection_region`

1. 服务关系：保护主藤，避免未来分支离根后再次穿越或长距离贴行。
2. 入口：不是生长入口；仅在未来合法根节点处允许短暂离开。
3. 经过：沿整条周期主藤采样，以局部法线和保护宽度形成闭合带。
4. 出口：无角色出口；只描述合法根部接触以外的禁入范围。
5. 邻接：所有角色通道必须在入口短段后离开它，之后不可重入；优先于角色区。
6. 适用原型：全部原型。
7. 禁止：把保护带当普通通道；用一条轴对齐矩形代替曲线带；允许离根后再进入。

### `seam_guard_region`

1. 服务关系：保留二方连续拼缝的入口和连续方向。
2. 入口：仅 seam/frontier/settle 语义可进入。
3. 经过：贴近 unit 左右周期接缝的保留带。
4. 出口：沿下一重复单元的连续方向离开。
5. 邻接：普通区和核心花位区不得占用接缝保留空间。
6. 适用原型：全部周期原型。
7. 禁止：普通枝在拼缝处被裁断；收束方向与下一单元不连续。

### `existing_structure_protection_region`：现有结构保护区

1. 服务关系：保护 StrictP0 中除主藤和目标花位以外已冻结的结构。
2. 入口：无生长入口。
3. 经过：由 StrictP0 的结构保护几何直接派生。
4. 出口：无。
5. 邻接：优先级等同硬禁入区，角色通道只能使用扣除后的剩余空间。
6. 适用原型：存在对应保护结构的原型。
7. 禁止：读取旧分支/旧区域来重建保护区；缩小保护区以适配候选。

## 角色生长区域

### `support_region`

1. 服务关系：建立“主藤波谷或侧翼—花位下侧”的托花关系。
2. 入口：目标花位附近波谷/波谷侧翼的主藤弧长区间；不是花位最近点；与 wrap 入口分离。
3. 经过：根段继承主藤切线，主弯转入花下空间，服务段在花位下方绕行。
4. 出口：在花位下侧连接扇区收窄并减速。
5. 邻接：与 wrap 服务同一花位，二者为不同 L1 根的兄弟角色；support 先生成，提供 wrap 外凸—内凹嵌合的参照。
6. 适用原型：主要为 SW1；SW3 必须使用 remote support。
7. 禁止：最近点短接、垂直上冲、直线连接、贴主藤滑行、用 L2 替代、穿花心、与 wrap 共用入口。

### `wrap_region`

1. 服务关系：沿目标花位外围形成侧下进入、环抱、回护和退出关系。
2. 入口：花位侧方/侧下方对应的独立主藤弧长区间；与 support 不同；根段先继承主藤切线。
3. 经过：受入口、花位椭圆、support 已占空间、外侧容量和退出方向共同影响，沿花缘外侧运行约四分之一至二分之一周长。
4. 出口：向外摆出或向主藤方向回收，宽度逐渐收窄。
5. 邻接：与 support 服务同一花位但不是其子枝；guide 不平行、不镜像、不重合；边界至少形成一处内凹—外凸嵌合。
6. 适用原型：主要为 SW1；SW3 不强制。
7. 禁止：作为 support 的 L2；固定半径/固定角圆弧；只在终点接近花；纯碰撞避让；机械描边；与 support 同根或镜像。

### `remote_support_region`

1. 服务关系：从远离最近点的主藤位置横向扫动，经花下绕行后连接花位下侧。
2. 入口：与目标花最近主藤点保持较大弧长距离的远端入口。
3. 经过：横向扫动是主运动，花下 waypoint 只可作为动态引导信息。
4. 出口：花位下侧连接扇区。
5. 邻接：先占据 SW3 核心通道，balance 再使用相对侧剩余空间；不强制 wrap。
6. 适用原型：`proto_sw_3_1`、`proto_sw_3_2`。
7. 禁止：最近点短接；强制 wrap；固定两段 Hermite 模板；竖直上冲。

### `balance_region`

1. 服务关系：补偿核心服务区造成的视觉重量并利用最大可用剩余扇区，不连接花位。
2. 入口：核心 support/wrap/remote support 已占用入口后，从相对侧剩余主藤区间进入。
3. 经过：横向展开，与核心区软嵌合但不覆盖主通道。
4. 出口：远离花心的开放剩余空间，长度目标为主服务结构的 0.50–0.75。
5. 邻接：生成优先级低于核心服务区；不得遮盖核心通道或形成完全对称镜像。
6. 适用原型：SW1 与 SW3 的冻结拓扑均要求；其他原型可按拓扑/容量启用。
7. 禁止：完全竖直、等长等权镜像、指向花心、形成新中心、默认 Y 叉、与核心区完全重合。

### `settle_region`

1. 服务关系：使 unit 后段降低曲率/密度并回归重复拼接方向。
2. 入口：unit 后段未占用主藤区间。
3. 经过：避开花位核心枝组并保留普通填充之前的接缝空间。
4. 出口：主藤或下一周期入口的连续方向。
5. 邻接：接缝出口空间优先于 ordinary fill。
6. 适用原型：需要末端收束的周期原型，容量允许 0 或 1。
7. 禁止：冲出上下边界、大圆卷头、拼缝折断、重复入口冲突、为填空生成多枝。

### `ordinary_fill_region`

1. 服务关系：仅处理核心、balance 和 settle 确定后的残余空间。
2. 入口：最终剩余且容量超过阈值的普通主藤区间。
3. 经过：避开核心和 settle 主通道，不服务花位。
4. 出口：剩余开放方向，不建立新中心。
5. 邻接：优先级最低，可不存在。
6. 适用原型：存在足够最终剩余容量的原型。
7. 禁止：侵入核心/settle；形成新视觉中心；为覆盖画布强制存在。

### `axis_flow_region`

1. 服务关系：保持 SW2 原型的轴向穿行或主运动关系。
2. 入口：来自 SW2 参考 morphology、主藤轴向与空白证据，不从花位角色拓扑猜测。
3. 经过：以横向主运动穿过可用空间，花位只参与结构关系和禁入边界。
4. 出口：沿轴向连续方向离开。
5. 邻接：不自动服务花位；不套用 SW1/SW3 核心组合。
6. 适用原型：`proto_sw_2_3`。
7. 禁止：强制 support+wrap、强制 remote support、未完成 morphology 审计就硬编码模板、形成长竖枝。

## R2B 固定实例的冻结解释

- 目标：`proto_sw_1_1` 的 `flower_1`，seed 仅作为运行矩阵元数据，不进入区域控制点。
- 必需硬区：一个 `flower_forbidden_region`；由周期主藤派生的至少一个 `backbone_protection_region`；seam guard 作为可视保留空间。
- 必需角色区：各一个 `support_region`、`wrap_region`、`balance_region`。
- support 与 wrap：同一 `service_flower_id`，不同 `region_id`、不同入口区间、不同 guide 摘要，且 guide 主方向差至少 25°。
- 所有角色区：闭合非自交曲线边界、至少 12 个 guide 样本、等数 tangent 样本、至少 5 个变宽样本、明确入口/出口/容量。
- 创建顺序：区域计划输入只能包含 Stage 2 分析、R2A 拓扑槽与目标花位 ID；曲线、候选、选择结果均为禁止输入。

## 检查点结论

上述解释与冻结规范逐项一致。可进入区域生成实现；若后续实现无法在不使用曲线/选择结果或模板化圆弧的情况下满足验收，R2B 必须失败并提出机制级根因，不得放宽指标。
