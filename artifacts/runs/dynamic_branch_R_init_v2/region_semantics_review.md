# 动态 BranchUnit R v2：区域语义理解

区域统一理解为“围绕主藤、花位与剩余空间生成的角色化软生长通道”，不是画布硬分区，也不是曲线生成后的标签。

## support_region

- 原型：SW1
- 服务：花位下侧托举关系
- 入口：花位对应主藤波谷或侧翼的独立可挂接区间
- 运动：根部继承主藤切线，延迟转向，横向进入花下
- 中段：经过花位下方的绕行空间
- 目标：花位下侧连接扇区，接点附近收缓
- 相邻关系：先于 wrap；与 wrap 内凹—外凸嵌合但主通道不重合
- 容量：独立 L1 一根
- 禁止：垂直上冲、直线连花、穿花心、长距离贴藤、由 L2 代替

## wrap_region

- 原型：SW1
- 服务：同一花位的外围围合与回护
- 入口：与 support 不同的独立主藤区间
- 运动：切线起步，进入花位侧下方，沿花缘外侧运行
- 中段：围合花位约四分之一到二分之一周长
- 退出：向外摆出或向主藤方向回收，必须有明确 exit direction
- 相邻关系：读取 support 已占用空间并与其嵌合；不得镜像或同根
- 容量：独立 L1 一根
- 禁止：support 的 L2、固定圆弧/半径/角度、只靠终点、机械描边

## remote_support_region

- 原型：SW3
- 服务：远端主藤到花位下侧的承托
- 入口：距花位最近主藤点较远的独立弧长区间
- 运动：切线起步并保持横向扫动
- 中段：经过花位下方
- 目标：花位下侧接入
- 相邻关系：先生成，balance 使用剩余相对侧；不要求 wrap
- 容量：独立 L1 一根
- 禁止：最近点直连、固定两段 Hermite、竖直上冲、强制 wrap

## balance_region

- 原型：SW1、SW3；SW2 仅在其形态允许时
- 服务：核心服务枝造成的视觉重量反侧
- 入口：核心区域和入口冻结后，从剩余可用主藤区间确定
- 运动：短于主服务枝并保持横向
- 中段/目标：最大可用剩余空白，不指向花心
- 退出：不形成新视觉中心
- 相邻关系：晚于 support/wrap/remote support，不能覆盖核心通道
- 容量：L1 零或一；若存在，长度为主服务枝的 0.50–0.75
- 禁止：预先固定、镜像复制、等长等权、默认 Y 叉

## settle_region

- 原型：全部 family 的 unit 后段
- 服务：密度下降、方向回归和下一周期入口
- 入口：unit 后段剩余且不占 seam 入口的位置
- 运动：继续横向，曲率与密度逐步下降
- 中段：避开核心花位枝组
- 退出：主藤或 seam 连续方向
- 相邻关系：在 ordinary fill 前保留
- 容量：L1 零或一
- 禁止：大卷头、冲出边界、拼缝裁断、多枝填空

## ordinary_fill_region

- 原型：全部 family，但可以不存在
- 服务：核心、balance 与 settle 之后仍有容量证据的残余空间
- 入口：最终剩余可挂接区间
- 运动：保持家族横向主运动
- 目标：局部留白，不服务核心花位
- 相邻关系：最低角色优先级，不能侵入核心与 settle 通道
- 容量：由剩余空间独立证明
- 禁止：均匀填满、制造新中心、替代核心角色

## axis_flow_region

- 原型：仅 `proto_sw_2_3`
- 服务：SW2 轴穿型的轴向主运动
- 入口：由 SW2 morphology、主藤轴向关系和空白证据决定
- 运动：保持横向轴向穿行
- 中段/目标：服从自身参考形态；花位主要作为关系与禁入边界
- 相邻关系：不强套 SW1/SW3
- 容量：由 SW2 审计后的家族能力决定
- 禁止：猜测固定模板、强制 support+wrap、强制 remote support、长竖枝

## flower_forbidden_region

- 原型：全部
- 服务：花位主体保护
- 来源：花位椭圆加冻结 padding
- 关系：support 仅接近下侧扇区；wrap 仅沿外围；其他枝不得进入
- 容量：不生成枝
- 禁止：缩小禁区迎合已有曲线

## backbone_protection_region

- 原型：全部
- 服务：防止分支离根后再次穿藤或长距离贴藤
- 来源：主藤完整周期几何及 ghost repeats
- 关系：只允许根部合法连接点接触；离开后不得重入
- 容量：不生成枝
- 禁止：当作普通通道、只检查终点

## seam_guard_region

- 原型：全部
- 服务：周期拼缝方向与下一单元入口空间
- 来源：repeat seam 和 unit envelope
- 关系：仅 seam/frontier/settle 可按声明进入
- 容量：保留空间，不直接等于枝数
- 禁止：普通枝被裁断、占堵下一周期入口、未声明端点停在 guard 内
