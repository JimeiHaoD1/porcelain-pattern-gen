# 缠枝纹分支规则示教编辑器：实施计划

## 0. 文档用途

本文档供新的 Codex 窗口直接实施。

当前只规划，不修改现有分支生成器，不改变 v23 结果，不实现递归，不接入大模型渲染。

编辑器的核心不是“调参数”，而是：

> 用户直接在真实生成结果上拖动、绘制和圈定合法区域，系统将这些操作保存为可重放的目标几何与合法参数域。

第一轮实现必须在 M0—M2 完成后停止，交给用户实际操作验收；不得擅自继续扩展为完整标注平台。

## 1. 目标

### 1.1 核心目标

建立一个本地浏览器编辑器，允许用户：

1. 载入当前固定深度实验的真实结果；
2. 锁定主干和花位；
3. 用鼠标选择任意 L1、L2、L3 分支；
4. 沿父枝拖动根点，改变挂载位置；
5. 拖动枝尖，改变长度和总体方向；
6. 拖动 Bézier 控制柄，改变曲率和弯曲位置；
7. 在父枝变形时保持所有后代真实挂载；
8. 撤销、重做、保存并精确重新载入；
9. 后续通过绘制挂载区、枝尖区、曲线包络和禁区表达合法范围；
10. 后续直接画新枝，并标记为必需枝或可选枝。

### 1.2 最终研究用途

编辑结果不是普通插图，而是“程序输出 → 用户目标”的结构化示教数据：

- 可以统计程序性偏差；
- 可以修正规则与合法参数范围；
- 可以形成动态分支数量的空间依据；
- 可以作为后续参数预测或候选排序的监督数据；
- 可以给结构约束的大模型渲染提供经过人工确认的输入。

### 1.3 成功定义

用户不再需要用文字描述“这根再长一点、向左一点、弯一些”，而是直接在图上完成修改；保存后，修改可以被程序读取、精确重放和比较。

## 4. 编辑器的正确交互模型

## 4.1 画布优先

界面主体必须是画布，不是侧栏参数表。

顶部只保留紧凑工具栏：

- 选择；
- 新增枝（后续阶段）；
- 根点范围；
- 枝尖合法区；
- 曲线包络；
- 禁区；
- 必需/可选；
- 撤销；
- 重做；
- 保存。

首轮 M0—M2 只启用：选择、撤销、重做、保存。

## 4.2 画布层级

从下到上依次为：

1. 上下边缘带；
2. 相邻 repeat 的只读幽灵副本；
3. 主干；
4. 花位；
5. 未选中分支；
6. 当前选中分支；
7. Bézier 控制线与控制柄；
8. 合法域与禁区；
9. 非阻塞警告。

主干与花位始终锁定，不能被鼠标移动。

## 4.3 分支选择

每条可见曲线同时绘制：

- 一条真实宽度的显示 path；
- 一条透明、较宽的 hit path。

点击 hit path 选择分支，不能要求用户精确点在线宽中心。

选中后显示：

- 根点；
- 枝尖；
- 当前每段 cubic 的控制点；
- 与父枝连接位置；
- 子枝根点。

## 4.4 根点拖动

用户拖动根点时：

1. 鼠标位置投影到父枝中心线；
2. 根点只能沿父枝移动；
3. 实时更新 `mount_fraction`；
4. 不能跳到其它父枝；
5. 不能停在父枝尖端；
6. 原始分支相对父枝的局部形状随新的父枝切向旋转和平移；
7. 该分支的后代递归跟随。

不得允许根点悬浮在画布空白处。

## 4.5 枝尖拖动

枝尖拖动直接控制：

- 根尖弦长；
- 总体方向；
- 是否靠近上下边缘带。

拖动时：

- `p3` 移到鼠标位置；
- 最末段 `p2` 默认随枝尖平移同一位移，以保持原有末段切线关系；
- 用户之后仍可单独拖动 `p2`；
- 不能自动增加卷头或任何末端对象。

## 4.6 曲率控制

每段 cubic 的 `p1`、`p2` 直接作为可拖动控制柄。

若一条枝包含两段 cubic：

- 中间连接点可见；
- 两侧控制柄可见；
- 默认维持 G1 连续；
- 用户拖动连接点时，两段共同更新；
- 首轮不允许增加第三段 cubic。

编辑器只允许当前“一段或两段 cubic”表示，不引入无限控制点。

## 4.7 父枝变化与后代跟随

这是首轮硬门槛，不能省略。

子枝不能保存为绝对位置后悬浮不动。每条子枝必须依赖：

- 父枝 ID；
- 父枝弧长比例；
- 挂载处局部切向与法向；
- 子枝控制点在父枝局部坐标系中的表示。

父枝变化后，按拓扑顺序更新所有后代。

## 5. 合法范围的直接绘制

合法范围不是用一排数值滑块输入，而是用户在画布上直接标记。

这一能力从 M3 开始实现。

## 5.1 三类信息

每条枝或每个 Unit 可以同时具有：

1. **preferred**：用户画出的理想结果；
2. **allowed**：可以接受的变化域；
3. **forbidden**：任何 seed 都不能进入的区域。

三类信息不能混为一个“容差值”。

## 5.2 根点合法区间

操作：

1. 选中分支；
2. 进入“根点范围”；
3. 在父枝上拖动两个端点；
4. 父枝上高亮一段弧长区间。

保存为：

```text
root_mount_range = [s_min, s_max]
```

其中 `s` 是父枝弧长归一化比例。

## 5.3 枝尖允许区域

用户在画布上用多边形或自由套索圈出枝尖可到达区域。

保存为：

```text
endpoint_region = polygon(points)
```

由目标根点与该区域自动推导：

- 总体方向范围；
- 根尖弦长范围；
- 上下边缘责任可能性。

首版不需要同时让用户重复画方向扇形和长度圆环。

## 5.4 曲线允许包络

以 preferred 曲线为中心复制两条边界曲线：

- boundary A；
- boundary B。

用户直接拖动两条边界曲线的控制柄，形成允许的形状包络。

保存：

- 两条边界曲线的 cubic 控制点；
- 采样后的闭合包络 polygon；
- 从包络反算出的曲率、弯曲位置和最大偏移范围。

边界曲线相交时显示警告，不得悄悄修复。

## 5.5 禁区

用户使用多边形或套索圈出：

- 花位保护区；
- 相邻 Unit 保留区；
- 不允许出现短枝簇的区域；
- repeat seam 拥挤区；
- 其它不允许分支进入的区域。

禁区可以绑定到：

- 全局；
- 某个 Unit；
- 某条父枝；
- 某一层级。

## 5.6 分支数量范围

数量不通过固定总数输入。

用户可以将分支标记为：

- `required`：必须存在；
- `optional`：合法空间允许时可以存在；
- `forbidden`：该位置不允许生成。

一个 Unit 的初步数量范围由：

```text
minimum = required_count
maximum = required_count + optional_slot_count
```

得到。

后续若需要表达“多个可选枝只能选一个”，再增加 alternative group；首轮不做。

## 6. 几何计算规则

## 6.1 父枝弧长投影

浏览器中将父枝按固定精度采样为折线，计算鼠标点到每个折线段的最近投影。

返回：

- 最近点；
- 对应累计弧长；
- 归一化 `mount_fraction`；
- 该位置的单位切向 `T`；
- 法向 `N=(-T_y,T_x)`。

保存时由 Python 核心再次计算和校验，不能只信任浏览器结果。

## 6.2 后代局部坐标变换

父枝变化前，子枝控制点 `q` 在旧挂载框架中的坐标为：

```text
u = dot(q - root_old, T_old)
v = dot(q - root_old, N_old)
```

父枝变化后：

```text
q_new = root_new + u * T_new + v * N_new
```

对子枝所有控制点执行该变换，再递归处理更深后代。

## 6.3 根点拖动时的自身变换

根点移动时，当前枝的控制点先以旧父枝挂载框架表达，再映射到新框架。这样根部方向会顺应父枝新的局部切向，而不是只做平移。

## 6.4 曲率与弯曲次数

编辑器实时显示但不自动修复：

- 归一化 sagitta；
- 曲率符号变化次数；
- 是否超过两次可见弯曲；
- 是否出现近直线；
- 是否出现硬折或极短控制柄。

用户可以暂时画出不合规曲线，但保存时必须明确记录 warning。不得偷偷改成“合格”。

## 6.5 Repeat 上下文

活动编辑区域仍是一个 256 px 周期。

画布显示：

- 当前周期：可编辑；
- 左右相邻周期：只读幽灵副本；
- 幽灵副本实时跟随当前周期更新。

左右边缘不作为严格抵达边缘；上下边缘仍显示严格边缘带。

- 保存时生成新的内容 hash；
- 所有新增、删除和修改必须出现在 `edit_summary`。

`D:\sdxl\chanzhi_sw_clean\artifacts\editor_sessions\<session_id>`

- `session.json`；
