# 照片与浮雕的结构保真重制规范 v1

## 目标

将主藤和父子分支关系可辨认、但受透视、材质、浮雕光影或背景干扰的图像，转换为可标注的二维线稿。重制模型只改变表现形式，不得补写结构事实。

## 可进入重制流程的最低条件

原图必须能够由人工完成以下判断：

- 连续主藤的位置和方向；
- 一级分支的真实附着点；
- 至少主要二级分支的父子关系；
- 花位存在时，承花或包花关系；
- 重复单元或可连续方向。

任一主要连接关系只能依靠生成模型猜测时，该图不得转成结构训练真值。

## 固定流程

1. 保存未经修改的原图并记录来源。
2. 在原图上先完成 v3 结构骨架标注。
3. 对弯曲边饰进行几何展平或透视校正。
4. 以人工骨架作为强约束，进行去材质、去光影和二维线稿重制。
5. 将重制线稿与人工骨架叠加检查。
6. 只有全部关键连接点通过检查，才可登记为 `structure_preserving_remake`。

## 一票否决项

- 主藤拓扑改变；
- 新增或删除主要分支；
- 分支附着点移动到另一条父枝；
- 花位移动、增加或消失；
- 重复接缝改变；
- 模型用看似漂亮的叶片遮住无法解释的连接；
- 把纯几何边饰改写成原图不存在的植物分支。

## 数据边界

- 重制样本只进入训练集，不进入验证集或测试集。
- 每个重制样本必须保留原图、人工骨架、重制图和叠加验收图。
- `source_parent_id` 指向真实来源，避免同源图跨训练/验证/测试集合。
- 第一阶段重制样本不超过训练集的 25%。
- 论文实验必须同时报告 `real_only` 与 `real_plus_remake`，验证重制数据是否真的带来收益。

## 必需元数据

- `sample_origin=structure_preserving_remake`
- `source_parent_id`
- `source_path`
- `annotation_svg`
- `remake_image`
- `overlay_preview`
- `qa_report`
- `human_structure_approved=true`
- `allowed_split=train`
