## 更新后的筛选规则

1. 优先二维黑白线稿，不再把真实器物照片作为主搜寻方向。
2. 样本必须具有可连续追踪的单一主藤，并至少能辨认花位、一级分支；核心样本还需出现可信的二级分支。
3. 排除几何填充、团花串联、徽章链、动物主导、拼贴模板和现代练习纸风格。
4. 保留完整条带用于视觉质量参考，另裁一个完整重复单元用于结构标注。
5. 程序生成图只能用于增强或候选提出，不能进入真实验证集。
6. 所有图片必须记录来源；论文插图、公开数据集或商业使用前需另行核查授权和原始出处。
