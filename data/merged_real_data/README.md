## 使用边界

- “筛选通过”只表示值得继续复审或标注，不等于已经形成训练金标。
- 部分图片来自论文或网页，版权字段仍需在论文发布、数据公开或附录分发前复核。
- 同一论文页面或网页原图可能产生多个不同裁剪；SHA-256 唯一不等于来源对象或纹样设计完全独立。
