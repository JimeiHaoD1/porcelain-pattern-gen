# 可实现的动态 BranchUnit 生成策略 V1

## 1. 目标

在不重写现有曲线生成器和全局求解器的前提下，使同一原型在不同 seed 下能够产生不同数量、不同根位节奏和不同层级落位的 BranchUnit 构图。

动态 V1 只解决三个问题：

1. L1 数量不再由原型固定；
2. 根位节奏能够适配不同 L1 数量；
3. L1-only、单 L2、双 L2 的数量和落位随最终 L1 数量变化。

它不引入区域规划、机器学习、额外视觉评分器或新的平行生成系统。

## 2. 为什么选择“先决定数量，再单次求解”

理论上可以给所有潜在槽位增加 `SKIP`，让数量与几何在同一个大型求解器中联合优化。但这会改变现有 solver 状态结构、候选语义、槽位覆盖合同和 Stage 4 输入，复杂度与失败面都过大。

动态 V1 采用更小的改法：

`主干容量 -> 动态 L1 数量 -> 对应数量的根位节奏 -> 现有 L1 全局求解器`

数量只推导一次，随后只运行一次正式 L1 求解。不尝试多个数量、不进行随机重试，也不在失败后静默减枝。

## 3. 保留与修改的边界

### 3.1 原样保留

- 主干 `s` 参数和局部切线/法向坐标；
- L1 Bézier 候选生成；
- L1 单条硬过滤；
- L1 全局 beam set solver；
- 冻结 L1 后生成完整 BranchUnit；
- Unit 内相交与净空判断；
- 跨 Unit 冲突图；
- Stage 5 确定性回溯选择；
- PNG 和结构 JSON 输出。

### 3.2 只修改

- seed 的允许范围；
- `_derive_lane_count()`；
- `_make_slots()` 的根位节奏生成；
- Stage 5 的层级顺序相位；
- manifest 中的动态数量说明。

## 4. 动态数量推导

### 4.1 输入量

每个原型已经具有：

- `preferred_l1_count`：当前视觉基线的中心数量；
- `candidate_l1_attachment_regions[].s_ranges`：允许挂载的主干区间；
- `minimum_root_spacing`：两条 L1 根位的最小周期距离；
- seed：本次构图变化来源。

`preferred_l1_count` 不再是最终数量，只作为动态区间的中心。

### 4.2 主干根位容量

先把左右两侧所有 `s_ranges` 投影到同一周期主干上并求并集。左右侧在同一 `s` 上不能重复计算容量，因为当前根位硬约束不区分侧别。

在区间并集上，按 `minimum_root_spacing` 计算最多能够放置多少个周期根位：

`root_capacity = periodic_max_separated_point_count(merged_s_ranges, minimum_root_spacing)`

该计算只回答“主干根位能否容纳”，不建立二维区域，也不预测最终曲线形状。

### 4.3 动态数量候选集

第一版只允许中心数量上下浮动 1，避免数量变化过大破坏当前已认可的视觉尺度：

`raw_counts = {preferred-1, preferred, preferred+1}`

再施加统一安全边界和主干容量：

`feasible_counts = {n | 5 <= n <= 9 and n <= root_capacity}`

因此：

- 原中心为 6 时，通常在 5、6、7 中选择；
- 原中心为 7 时，通常在 6、7、8 中选择；
- 原中心为 8 时，通常在 7、8、9 中选择。

这一步不会把所有原型强制成同一个数量区间。

### 4.4 seed 如何选择数量

新增一个构图级连续变量 `density_u ∈ [0,1)`，由 `prototype_id + seed` 确定。

把可行数量升序排列后，用 `density_u` 选择低、中或高容量档。选择是可复现的，但不是 `random.randint()`，因为不可行的数量已经被主干容量排除。

建议第一版使用均匀分档：

- `density_u < 1/3`：选择低数量；
- `1/3 <= density_u < 2/3`：选择中数量；
- `density_u >= 2/3`：选择高数量。

输出中记录：中心数量、主干容量、可行数量集合、`density_u` 和最终数量，供研究时解释数量来源。记录字段不作为视觉通过证据。

## 5. 可变数量下的根位节奏

当前 `root_rhythm_quantiles` 只适配原固定数量。动态数量不能在长度不匹配时退回等距根位，否则 6、7、8 条只是均匀排布的不同版本。

### 5.1 节奏重采样

对原型已有的周期根位序列执行以下步骤：

1. 按周期顺序排列原始根位；
2. 转换成相邻周期 gap 序列；
3. 把累计 gap 曲线重采样成最终数量 `N` 个根位；
4. 使用 seed 对每个 gap 施加小幅乘性变化；
5. 重新归一化，使所有 gap 之和仍为 1；
6. 加上现有 `flow_phase`；
7. 将结果作为槽位首选 `root_s`，实际根位仍由现有候选区和全局求解器决定。

建议 gap 变化范围限制为 `0.85–1.15`。它只改变节奏，不直接改变曲线控制点。

### 5.2 必须保持的性质

- 不生成完全等距根位；
- 不把根位写成固定坐标；
- 不让不同数量共享完全相同的前 N 个根位；
- 不绕过 `candidate_l1_attachment_regions`；
- 最终根位仍必须通过现有周期间距与相交约束。

## 6. L1 几何生成不重写

动态数量确定后，继续使用当前正式 L1 生成机制：

`槽位 -> 候选挂载区 -> root_s -> 局部切线/法向 -> 长度层次 -> 曲率参数 -> 硬过滤`

全局 solver 的输入槽位数从固定 7 变为动态 `N`，其余候选类型和曲线公式不变。

beam 容量当前已经按 `len(slots)^2` 缩放，5–9 条范围无需更换求解算法。

如果动态数量对应的正式求解不可行，本次任务明确返回 `dynamic_l1_layout_infeasible`。第一版不尝试 `N-1`、不换 seed、不自动删枝。

## 7. 层级随 L1 数量缩放

Stage 5 已经能够根据 `lane_count` 和层级比例用最大余数法计算整数数量，因此不需要新增层级容量规划器。

当前比例继续作为第一版中心：

- L1-only：0.276；
- 单 L2：0.398；
- 双 L2：0.326。

动态 L1 数量会自然得到不同整数结构，例如：

| L1 数量 | L1-only | 单 L2 | 双 L2 | L2 总数 |
|---:|---:|---:|---:|---:|
| 6 | 2 | 2 | 2 | 6 |
| 7 | 2 | 3 | 2 | 7 |
| 8 | 2 | 3 | 3 | 9 |

第一版不再设计第二套“层级容量场”。如果某个槽位的某类候选因净空失败，现有回溯器会在其他槽位安置该层级。

## 8. 层级落位变化

即使数量变化，如果 Stage 5 永远使用同一层级循环，双 L2 仍可能反复落在相似序号的槽位。

最小改法是使用 seed 旋转现有 `class_cycle`：

`rotated_cycle = rotate(class_cycle, seed_phase)`

同时旋转同一层级内部的参数层次优先级。这样只改变候选访问顺序，不修改冲突约束，也不增加随机视觉评分器。

## 9. 任意 seed 与批量生成

移除当前 `SEEDS = (4101, 4102, 4103)` 的生产限制。正式接口接受非负 32 位整数 seed。

4101–4103 继续作为人工对照案例，不再是唯一允许输入。

批量生成器只需要遍历 seed：

`prototype × seed -> density_u -> N -> slots -> one global solve -> BranchUnits`

动态 V1 不增加跨样本去重器。先观察数量、根位和层级变化是否真实改善视觉多样性，再决定是否需要批次级重复控制。

## 10. 实现顺序

### D1：动态数量与任意 seed

修改：

- `global_l1_flow.py`
  - 允许任意非负 seed；
  - 新增 `_periodic_root_capacity()`；
  - 新增 `_derive_dynamic_l1_count()`；
  - `_derive_lane_count()` 消费动态结果。
- `run_stage3b_l1_flow.py`
  - 移除 argparse 的固定 seed choices。
- `STAGE3B_L1_FLOW_CONTRACT_V2.json`
  - 将固定 seed 列表改成 seed 范围；
  - 增加动态数量策略字段。

完成 D1 后，先输出同一原型多个 seed 的 L1-only 预览，确认数量变化没有破坏整体流向。

### D2：根位节奏重采样

修改：

- `global_l1_flow.py`
  - 新增 `_resample_periodic_root_rhythm()`；
  - `_make_slots()` 不再因数量变化退回等距布局。

D2 不修改曲率和长度参数。

### D3：动态层级落位

修改：

- `stage5_global_unit_selection.py`
  - 层级计数继续按动态 `lane_count` 推导；
  - 使用 seed 旋转层级类别和参数层次访问顺序。
- `STAGE5_GLOBAL_SELECTION_CONTRACT_V2.json`
  - 明确层级数量由实际 L1 数量推导；
  - 明确 seed 只改变合法候选顺序，不降低硬约束。

完成 D3 后再输出完整 BranchUnit 预览。

## 11. 最小验收方式

自动检查只保留：

- 单周期和相邻周期是否相交；
- 动态数量是否真正进入正式 `lanes` 和最终选择。

视觉验收只看少量代表案例：

- 低数量案例；
- 中数量案例；
- 高数量案例。

人工判断整体流向、疏密、层级和空白是否成立。数值指标不自动批准视觉结果。

## 12. 明确不做

动态 V1 不做以下内容：

- 不恢复 R 区域规划；
- 不建立二维 occupancy mask；
- 不给潜在槽位增加 `SKIP` 并重写联合求解器；
- 不尝试多个 L1 数量后择优；
- 不扩大随机重试；
- 不增加机器学习模型；
- 不建立自动审美评分；
- 不同时修改根位、曲率、长度和 L2 形状参数；
- 不用固定坐标模板制造表面差异。

## 13. V1 成功后的能力

完成后，同一原型的不同 seed 将能够产生：

- 不同的 L1 数量；
- 与数量匹配的非等距根位节奏；
- 不同的 L1-only、单 L2、双 L2 整数配比；
- 不同槽位上的层级落位；
- 在原有曲率和挂载范围内的连续几何变化。

这不是无限制随机生成，但已经把当前“固定数量、固定层级结构下的参数扰动”升级为可实现、可控制的动态 BranchUnit 生成。
